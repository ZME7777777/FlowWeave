# Decompose requirements

Create stable requirement IDs. Separate functional points, business rules, boundaries, non-functional constraints, and acceptance scenarios while preserving PRD traceability.

## Output discipline

Return reviewable structured findings with requirement and evidence references. Never perform human-only start, branch, acceptance, or cancellation actions.
