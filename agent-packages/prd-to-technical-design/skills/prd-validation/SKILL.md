# Validate PRD structure

Check document identity, revision, goals, actors, scope, constraints, acceptance criteria, contradictions, and missing information. Return findings; do not repair unknown content.

## Output discipline

Return reviewable structured findings with requirement and evidence references. Never perform human-only start, branch, acceptance, or cancellation actions.
