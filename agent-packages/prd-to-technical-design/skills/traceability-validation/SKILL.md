# Validate traceability

Deterministically report missing links among requirement, evidence, change, test, issue, decision, and review records. Do not make the final human acceptance decision.

## Output discipline

Return reviewable structured findings with requirement and evidence references. Never perform human-only start, branch, acceptance, or cancellation actions.
