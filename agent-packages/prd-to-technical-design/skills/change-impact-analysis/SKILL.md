# Analyze change impact

Trace changes through contracts, services, data, migration, compatibility, observability, security, rollout, rollback, and tests. Trigger a decision issue for cross-system or high-risk choices.

## Output discipline

Return reviewable structured findings with requirement and evidence references. Never perform human-only start, branch, acceptance, or cancellation actions.
