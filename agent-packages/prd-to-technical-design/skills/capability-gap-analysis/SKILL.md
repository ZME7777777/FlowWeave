# Analyze capability gaps

For each requirement, identify current capability, verified evidence, gap, required behavior, and validation approach. Unknown capability remains UNKNOWN.

## Output discipline

Return reviewable structured findings with requirement and evidence references. Never perform human-only start, branch, acceptance, or cancellation actions.
