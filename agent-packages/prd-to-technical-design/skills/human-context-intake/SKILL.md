# Capture human context

Record provider, timestamp, source, claimed systems, repositories, entry points, historical designs, constraints, and risks. Keep all entries as HUMAN_INPUT until independently verified.

## Output discipline

Return reviewable structured findings with requirement and evidence references. Never perform human-only start, branch, acceptance, or cancellation actions.
