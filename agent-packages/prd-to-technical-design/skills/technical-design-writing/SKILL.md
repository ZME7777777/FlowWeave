# Render technical design

Generate the standard technical design only from reviewed structured artifacts. Include evidence references, alternatives, risks, open issues, rollout, rollback, and verification.

## Output discipline

Return reviewable structured findings with requirement and evidence references. Never perform human-only start, branch, acceptance, or cancellation actions.
