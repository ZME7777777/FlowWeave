# OPS-60 会话归档三态筛选实现验收

2026-10-29，根据用户截图，在会话管理的状态筛选中增加“全部”，选项顺序为
“全部 / 未归档 / 已归档”。初次进入和重置均选择“全部”；切换根工作区、普通
工作区或已归档工作区时保留用户当前的状态筛选。

“全部”省略请求的 archived 参数，复用后端已有的三态查询；另外两个选项分别
传 false / true。状态筛选纳入重置按钮的可见条件，查询缓存仍按工作区和筛选值
隔离。沿用 LaunchOptionMenu 及其键盘、Escape 和视口边界行为。

验证：Web typecheck、受影响源码及测试 ESLint、git diff 检查通过；7 项会话管理
Chromium 用例通过，涵盖默认混合列表、两种独立状态、重置、工作区切换、键盘
返回全部、分页、恢复确认及批量删除。旧分页用例因默认列表新增归档项而由
末页 5 条变为 6 条，修正期望后定向复跑通过。1440 宽截图已人工核对。

本片只修改 Web，无 API、迁移或 Runtime 改动。本记录为实现验收，尚未部署；
